Rumep Fontları Kullanım Kılavuzu

Fontlarımızı farklı platformlarda nasıl kullanabileceğinize dair detaylı rehber.

Uygulama Geliştiricileri İçin:
  1. RumepLogosSVG.ttf dosyasını indirin.
  2. Dosyayı projenizin res/font/ klasörüne kopyalayın.
  3. XML layout dosyanızda TextView'a şu özelliği ekleyin: 
    android:fontFamily="@font/rumeplogossvg"
Son Kullanıcılar İçin (Klavye Uygulamaları):

Eğer bu fontu destekleyen bir klavye uygulaması (Gboard, SwiftKey vb. özel temalarla) kullanıyorsanız:

  • Font dosyasını cihazınıza indirin.
  • Kullandığınız klavye uygulamasının "Tema" veya "Font" ayarlarına gidin.
  • "Özel Font Ekle" seçeneğinden indirdiğiniz .ttf dosyasını seçin.

Konfigürasyon Profili İle Yükleme:

iOS cihazlara font yüklemek için genellikle bir "Font Yükleyici" uygulaması (iFont vb.) kullanmanız gerekir.

  1. App Store'dan iFont gibi bir uygulama indirin.
  2. Rumep fontunu indirin ve "iFont ile Aç" seçeneğini seçin.
  3. Uygulama içindeki "Install" (Yükle) butonuna basın.
  4. Ayarlar > Genel > Profil yolunu izleyerek yüklenen profili onaylayın.
  5. Artık Pages, Keynote gibi destekleyen uygulamalarda fontu kullanabilirsiniz.
Not: iOS sistem fontunu tamamen değiştirmek jailbreak olmadan mümkün değildir. Bu işlem sadece font destekleyen uygulamalarda (örneğin tasarım uygulamaları) fontu kullanmanızı sağlar.

Windows
  1. .ttf formatındaki font dosyasını indirin.
  2. İndirdiğiniz dosyaya sağ tıklayın.
  3. "Yükle" (veya "Tüm kullanıcılar için yükle") seçeneğine tıklayın.
  4. Word, Photoshop gibi programlarda "RumepLogos" adıyla fontu bulabilirsiniz.
Mac (macOS)
  1. Font dosyasını indirin ve çift tıklayın.
  2. Açılan pencerede "Fontu Yükle" butonuna tıklayın.
  3. Font Book (Font İzlencesi) uygulamasına eklenecektir.

Web sitenizde kullanmak için WOFF2 formatını tercih etmeniz önerilir.

@font-face {
    font-family: 'RumepLogos';
    src: url('RumepLogosSVG.woff2') format('woff2'),
         url('RumepLogosSVG.ttf') format('truetype');
    font-weight: normal;
    font-style: normal;
}

/* Kullanım Örneği */
.ikon {
    font-family: 'RumepLogos', sans-serif;
}
